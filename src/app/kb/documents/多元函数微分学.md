# 全微分与多元复合函数求导

## 考情与定位
数学二多元微分部分的核心考点。偏导、全微分、复合函数链式法则是三个连着考的点，常以计算题形式出现。

## 常见考法
1. 求一阶、二阶偏导数。
2. 判断函数在某点是否可微（用全微分定义）。
3. 多元复合函数求导：链式法则的树状展开。
4. 隐函数求导（由一个方程确定 z=z(x,y)）。

## 易错点
1. **二阶混合偏导相等的条件被忽略**——只有当二阶混合偏导连续时才相等，不是无条件成立。
2. 链式法则漏项：z 依赖 u、v，u、v 又依赖 x、y 时，必须把两条路径都算上。
3. 隐函数求导公式里的符号：∂z/∂x = −F_x/F_z，负号最容易漏。
4. 全微分存在要求偏导存在**且**函数在该点连续（仅有偏导不保证可微）。

## 解题思路
多元复合求导画「依赖树」：从最外层因变量出发，每条到自变量的路径相乘，不同路径相加。
隐函数求导先构造 F(x,y,z)=0，再套公式，注意负号。

## 验收标准
能独立完成 5 道复合函数/隐函数求导题并全对，且能说清"为什么二阶混合偏导不总相等"。
