# 矩阵运算与转置

## 考情与定位
线代的地基。单独考计算的分值不高（选择填空），但**矩阵运算出错会直接毁掉后面所有题**：特征值、二次型、方程组都建立在矩阵基本运算之上。

## 常见考法
1. 矩阵乘法、幂运算（特别是求 Aⁿ：找规律或用对角化）。
2. 转置、伴随、逆的混合运算与恒等式变形。
3. 求逆矩阵：伴随矩阵法（2~3 阶）或初等变换法。
4. 解矩阵方程 AX=B 或 XA=B：注意**左乘右乘不能交换**。
5. 抽象矩阵的运算律判断（给一个等式问哪些选项成立）。

## 易错点
1. **矩阵乘法不可交换**：AB≠BA。凡是"约掉"矩阵的步骤都要检查是否合法。
2. (AB)ᵀ=BᵀAᵀ、(AB)⁻¹=B⁻¹A⁻¹——**顺序必须颠倒**，这是最高频错误。
3. (A+B)²≠A²+2AB+B²（因为 AB≠BA），只有 A、B 可交换时才成立。
4. (AB)⁻¹ 存在要求 A、B 都可逆，但 AB 可逆只要求 |AB|≠0，两者不等价。
5. 转置与逆的顺序：((A⁻¹)ᵀ)⁻¹ == (Aᵀ)⁻¹，可记作 (A⁻¹)ᵀ = (Aᵀ)⁻¹。

## 解题思路
遇到矩阵等式先想能不能用"可逆 → 两边同乘"化简，注意**乘在左边还是右边**；
遇到求 Aⁿ，先算 A²、A³ 找规律，或用秩 1 矩阵公式 A = αβᵀ ⟹ Aⁿ = (βᵀα)^(n−1)·A。

## 验收标准
能默写全部矩阵运算律（含转置/逆/伴随的六条恒等式）并在 5 道混合运算题上全对。

# 行列式的性质与计算

## 考情与定位
每年都考，通常 4~5 分。计算本身有套路（化三角形），难点在**抽象行列式的性质运用**和 **|kA| 的系数**。

## 常见考法
1. 数字行列式计算：化上三角或降阶展开。
2. 抽象行列式：给出 |A|，求 |kA|、|A*|、|A⁻¹|、|Aᵀ| 等。
3. 含参数行列式：行列式为 0 的条件（与秩、方程组有非零解联动）。
4. 爪型、行和相等的行列式：用特殊技巧处理。
5. 分块行列式。

## 易错点
1. **|kA| = kⁿ|A| 而不是 k|A|**（n 是阶数）——最高频错误。
2. |A*| = |A|^(n−1)，|A⁻¹| = |A|⁻¹，这几个公式必须背熟。
3. 行列互换要变号、某行乘 k 则行列式乘 k、行加到另一行不变——三条基本性质用混。
4. 爪型行列式不会处理，硬展开导致计算量爆炸。
5. 分块矩阵行列式：只有对角分块（另一块为 0 阵）才能直接相乘。

## 解题思路
数字行列式：先找某行某列尽可能多的 0 → 展开降阶，或直接**化上三角**（目标是对角线元素好算）。
抽象行列式：把要求式往 |A| 上凑，用 |AB|=|A||B| 和 |kA|=kⁿ|A| 两条。
爪型：用"对角线元素减去某行的倍数"把爪子消掉。

## 验收标准
能独立完成 5 道行列式计算（含 2 道抽象型）并全对，能准确说出 |3A| 与 |A| 的关系（3 阶矩阵）。

# 特征值与特征向量的计算

## 考情与定位
线代大题的主角之一，常与相似对角化、二次型连考。计算量大但要按固定套路走，属于"会了就很稳"的题。

## 常见考法
1. 求特征值：解特征方程 |λE − A| = 0。
2. 求特征向量：对每个 λ 解齐次方程组 (λE − A)x = 0，取基础解系。
3. 判断能否相似对角化：n 个线性无关特征向量。
4. 利用特征值求行列式（|A| = Πλᵢ）与迹（tr(A) = Σλᵢ）。
5. 已知特征值/特征向量反求矩阵中的参数。

## 易错点
1. **|λE − A| 与 |A − λE| 混用**，虽然特征值相同，但中间过程容易差符号。
2. 特征向量要取**基础解系**（全部线性无关的解向量），只写一个会漏解。
3. 忘记"k 重特征值必须有 k 个线性无关的特征向量才能对角化"这个条件。
4. 实对称矩阵一定可对角化（且可用正交矩阵），这个性质忘用会走弯路。
5. 用 |A| = Πλᵢ 时符号出错（负特征值的乘积）。
6. 特征向量不能是零向量。

## 解题思路
固定三步：
① 算 |λE − A|，解出全部特征值（注意重根）；
② 对每个 λ 解 (λE−A)x=0，求基础解系；
③ 按需组装 P 和 Λ，验证 P⁻¹AP = Λ。
**验算技巧**：tr(A) 是否等于 Σλᵢ、|A| 是否等于 Πλᵢ——两个快速自检。

## 验收标准
能独立完成 5 道（含实对称矩阵正交对角化）并全对，且能用迹与行列式自检答案。

# 线性相关与线性无关的判定

## 考情与定位
抽象证明题的核心考点，也是判断方程组解的结构、矩阵秩的基础。选择题常考"给若干条件判断相关/无关"。

## 常见考法
1. 给具体向量组，判断线性相关性（求秩）。
2. 抽象向量组的相关性证明：用定义设 k₁α₁+…+kₙαₙ=0，证所有 k 为 0。
3. 部分组与整体组的相关性关系（部分相关 ⟹ 整体相关）。
4. 与秩的关系：向量组线性无关 ⟺ 秩 = 向量个数。
5. 加向量后相关性变化（n+1 个 n 维向量必相关）。

## 易错点
1. **向量个数 > 维数时必线性相关**（这条常被忘，能秒杀一批题）。
2. "部分组无关"推不出"整体无关"（反过来才成立：整体无关 ⟹ 部分无关）。
3. 用定义证明时，只证了"存在不全为 0 的 k 使等式成立"就下结论，方向反了。
4. 混淆"线性相关"与"某个向量可由其余表示"——后者要求那个向量确实在组里且相关。
5. 矩阵行向量组和列向量组的秩相同，但相关性可能不同，不能混用。

## 解题思路
判定的两条主线：
**具体向量**：排成矩阵求秩，秩 < 个数 ⟹ 相关。
**抽象向量**：用定义，把已知条件（如 Aα=λα）代入凑出 k 的关系。
遇到"证明某组无关"的题，考虑反证法：设相关，推出与已知矛盾。

## 验收标准
能独立完成 5 道判定/证明题，且能说清"为什么 n+1 个 n 维向量必线性相关"的直观理由。

# 二次型的标准形

## 考情与定位
数学二线代的压轴考点，常与特征值合并考查。核心是**用正交变换化标准形**，本质就是实对称矩阵的正交对角化。

## 常见考法
1. 写出二次型的矩阵 A（注意：**交叉项系数要除以 2**）。
2. 用正交变换 x=Qy 化标准形：求 A 的特征值，标准形就是 λ₁y₁²+λ₂y₂²+λ₃y₃²。
3. 判断正定性：全部特征值 > 0，或各阶顺序主子式 > 0。
4. 用配方法化标准形（不要求正交变换时更简单）。
5. 求二次型的秩（= 矩阵的秩 = 非零特征值个数）。

## 易错点
1. **写二次型矩阵时交叉项系数忘了除以 2**——这是最经典的错误。x₁x₂ 的系数 a 对应 a₁₂ = a₂₁ = a/2。
2. 正交变换要求 Q 是正交矩阵（QᵀQ=E），用配方法得到的变换矩阵一般不正交。
3. 正定性判定用了"顺序主子式"，但那是**充分条件**（对实对称矩阵其实充要），别人用特征值时不要混淆。
4. 特征值算出重根时，正交化步骤漏掉（Schmidt 正交化）。
5. 标准形与规范形的区别搞混（规范形要求系数是 ±1 或 0）。

## 解题思路
正交变换法四步：
① 写出二次型矩阵 A（交叉项系数除 2）；
② 求 A 的全部特征值；
③ 对每个特征值求特征向量，重根的要正交化；
④ 单位化后组成 Q，标准形系数即特征值。
**验算**：特征值之和应等于矩阵的迹。

## 验收标准
能独立完成 3 道化标准形题（含 1 道重根需正交化）并全对，且写矩阵时交叉项系数不出错。
