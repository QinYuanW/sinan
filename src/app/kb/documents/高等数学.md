# 极限的基本计算（等价无穷小 / 洛必达 / 泰勒）

## 考情与定位
数学二的开篇必考项，几乎每年都在选择填空出现，也是大题的第一步。三类方法常在同一道题里配合使用：先看能不能用等价无穷小化简，化简后仍是未定式再上洛必达或泰勒。

## 常见考法
1. 0/0 与 ∞/∞ 型未定式的直接计算。
2. 幂指函数型（1^∞、0^0、∞^0）：先取对数化成 0·∞，再化成分式。
3. 含变限积分的极限：先洛必达再等价无穷小。
4. 求参数：已知极限存在且等于某值，反求 a、b。

## 易错点
1. **等价无穷小只能在乘除中整体替换**，加减法中替换会丢阶。典型：x→0 时 sinx−tanx 不能替换成 x−x=0。
2. **泰勒展开阶数取错**——这是最高频的失分点。判断标准：分母是 x 的几阶，分子就展开到几阶；不能少展开也不能多展开（多展开不扣分但浪费时间）。
3. 洛必达要求分子分母**分别可导**且极限存在，用了之后如果还是未定式可以再用，但要注意每次用完先化简。
4. 1^∞ 型忘了先取对数，直接代 1 得 1，这是概念性错误。

## 解题思路
先判类型（七种未定式），再选武器：
等价无穷小最快（乘除结构）→ 洛必达次之（求导出得快的题）→ 泰勒最稳（复杂结构、加减混合）。
三者不是互斥的，实战常是"等价替换化简 → 泰勒展开到同阶 → 合并同类项"。

## 验收标准
能独立完成 5 道综合极限题并全对，其中至少 2 道需要泰勒展开到三阶以上，且能说清每道题为什么选这个阶数。

# 导数与微分的定义

## 考情与定位
定义本身直接考的不多，但**用定义求导**是每年都可能出现的"送分或送命"题：会的人 2 分钟，不会的人卡死在第一步。分段函数在分界点的可导性必须用定义判断，这是硬性考点。

## 常见考法
1. 用定义求 f'(x₀)：给出极限式，凑成 [f(x₀+Δx)−f(x₀)]/Δx 的形式。
2. 分段函数在分界点是否可导：左右导数定义分别求，比较是否相等。
3. 已知 f(x₀) 处可导，求含 f 的极限表达式。
4. 导数定义的几何意义：切线斜率，判断曲线在某点是否有切线。

## 易错点
1. **在分界点误用求导公式**——分段函数的两段表达式在分界点各自求导得到的是两边的导函数值，它们相等**不能**推出该点可导，必须用定义验证左右导数。
2. 凑定义时把 Δx 和 x 的关系搞混，特别是 x→x₀ 与 Δx→0 的换算。
3. 忘记"可导必连续"这个必要条件，用它排除错误选项时反而找不到。
4. 求导得到的是 f'(x₀) 还是 f'(x) 没分清，导致后面代入出错。

## 解题思路
看到"用定义求导"就老老实实写极限式，不要试图绕过；看到"分段函数可导性"，先算左右极限（判连续），再用定义算左右导数。
记忆锚点：**连续 ⊂ 可导 ⊂ 可微**，反向不成立。

## 验收标准
能用定义独立推出分段函数（含 |x| 型）在分界点可导性结论，并在 3 道不同形式的题上全对。

# 微分中值定理的证明与应用

## 考情与定位
数学二证明题的主力。罗尔定理是根，拉格朗日中值定理是干，柯西中值定理是分支。考试里通常要求"证明存在 ξ 使某个等式成立"，这类题的构造是核心难点。

## 常见考法
1. 直接使用拉格朗日中值定理证明不等式。
2. 构造辅助函数后用罗尔定理，证明存在 ξ 满足某个含 f(ξ)、f'(ξ) 的等式。
3. 两个中值点的问题：需要两次使用中值定理（通常先用一次拉格朗日，再用一次罗尔）。
4. 证明方程在区间内有根：零点定理 + 单调性。

## 易错点
1. **辅助函数构造不出来就硬凑**——正确做法是从要证的等式出发反推：把 ξ 换成 x，移项使一边为零，看的那个式子像谁的导数。
2. 忘记验证定理条件（闭区间连续、开区间可导、端点函数值相等），尤其是罗尔的 f(a)=f(b)。
3. 用中值定理证明不等式时，ξ 的范围没约束好，导致不等号方向错。
4. 区间端点取错（把开区间当闭区间用）。

## 解题思路
反推法构造辅助函数三步：
① 把结论里所有 ξ 换成 x；
② 移项使右边为 0，得到 F(x)=0 的形式；
③ 观察 F(x) 能写成谁的导数——通常需要乘 e^(kx) 或除以 xⁿ 来凑。
两个中值点则考虑"分区间各用一次"。

## 验收标准
能独立构造 5 个不同形式的辅助函数并完成证明，且能说清"为什么乘 e^x 而不是 e^(2x)"。

# 不定积分的基本方法与基本公式

## 考情与定位
计算基本功，直接影响后面所有积分相关题目。数学二对积分计算的要求高于数学一（因为不考级数，积分的比重更大）。换元与分部是两把主钥匙。

## 常见考法
1. 直接使用基本积分表（约 20 个公式）。
2. 第一类换元（凑微分）：∫f(φ(x))φ'(x)dx 型。
3. 第二类换元：根式代换（三角代换、倒代换），处理含 √(a²−x²)、√(x²±a²) 的式子。
4. 分部积分：∫udv = uv − ∫vdu，用于多项式×指数/三角函数、对数/反三角×多项式。
5. 有理函数积分：先做部分分式分解。

## 易错点
1. **忘记加常数 C**——每年都有人丢这个分。
2. 换元后忘记**换回原变量**，最后答案里还留着 t。
3. 分部积分的 u、dv 选反了，导致越积越复杂。选 u 的口诀：**反·对·幂·指·三**（反三角、对数、幂函数、指数、三角，排在前的作 u）。
4. 三角代换后忘记处理 dx 与变量的范围（特别是根号开出来要不要加绝对值）。
5. 部分分式分解时待定系数算错。

## 解题思路
看到积分先问三个问题：
① 能不能直接查表？ ② 能不能凑微分（第一类换元）？ ③ 是不是两个不同类型函数的乘积（→ 分部）？
含根式的优先三角代换；有理分式先分解；实在不行再考虑凑。

## 验收标准
能独立完成 10 道积分计算且答案全对，覆盖凑微分、三角代换、分部积分、有理函数分解四类。

# 定积分的几何应用（面积、旋转体体积）

## 考情与定位
数学二的应用题主力，几乎每年一道大题。核心是**把几何量写成定积分**，计算本身不难，难在"列式子"。

## 常见考法
1. 求平面图形面积：直角坐标下 ∫(上−下)dx，参数方程下的面积公式。
2. 求旋转体体积：绕 x 轴 V=π∫y²dx；绕 y 轴 V=2π∫x·y dx（柱壳法）。
3. 求旋转体侧面积：S=2π∫|y|√(1+y'²)dx。
4. 求平面曲线的弧长（直角坐标 / 参数方程）。
5. 求平行截面面积已知的立体体积。

## 易错点
1. **上下限写反**，导致面积为负。
2. 分段函数的图形分块没分开算，尤其是曲线与坐标轴围成的区域有正有负时没取绝对值。
3. 柱壳法和圆盘法用混：绕 y 轴用柱壳（2πxy）比用圆盘（πx²dy）简单，但要看清是对谁积分。
4. 参数方程求面积时忘记换算 dx = x'(t)dt，上下限也没换成 t 的范围。
5. 忘乘 π 或忘乘 2π。

## 解题思路
画图 → 找交点定上下限 → 判断用哪种公式 → 写积分 → 算。
**画图这一步不能省**，很多错误（上下限、上下方、正负）都能提前避免。

## 验收标准
能独立完成 5 道应用题并全对，其中至少 1 道需要分段计算、1 道绕 y 轴。

# 二重积分在直角坐标下的计算

## 考情与定位
数学二的重头戏，每年必考且常是压轴大题。直角坐标下的核心是**化为累次积分**与**交换积分次序**，后者是高频考点。

## 常见考法
1. 直接化为累次积分：X 型区域（先 y 后 x）或 Y 型区域（先 x 后 y）。
2. 交换积分次序：给出一个已写好的累次积分，要求交换顺序。
3. 选择合适次序化简：原次序积不出来，换序后立刻能积。
4. 利用对称性与奇偶性化简（区域关于坐标轴对称时）。
5. 分块积分：积分区域需要分成两块才能用单一累次积分表示。

## 易错点
1. **换序时积分限写错**——这是最高频错误。正确做法：先画出积分区域，再按新次序重新确定内外层的上下限，不能直接把上下限对调。
2. 内层积分限含外层变量时搞混（如 X 型区域内层是 y 的限，可含 x；外层是常数）。
3. 被积函数里有绝对值或 max/min 时忘了分区域。
4. 用对称性化简时没验证被积函数关于该变量的奇偶性。

## 解题思路
换序四步：
① 画出区域 D 的图形；
② 从原积分限反推出区域的边界曲线；
③ 按新次序重新描述区域（X 型还是 Y 型）；
④ 写出新的累次积分。
**画图是唯一可靠的方法**，纯代数推演容易漏边界。

## 验收标准
能独立完成 5 道换序题且限全对，并能说明"为什么这道题必须换序"（通常是原次序内层积不出）。

# 一阶线性微分方程

## 考情与定位
微分方程是数学二的固定大题（通常一道 10~12 分）。一阶线性是基础模型，通解公式必须背到条件反射，因为它是后面二阶方程的基础。

## 常见考法
1. 标准形式 y' + P(x)y = Q(x)，直接套通解公式。
2. 需要先化为标准形式（把 y' 的系数除成 1）。
3. 伯努利方程 y' + P(x)y = Q(x)yⁿ：换元 z = y^(1−n) 化为一阶线性。
4. 齐次方程 y' = f(y/x)：换元 u = y/x。
5. 应用题：根据物理/几何条件列方程（增长率、冷却、曲线性质）。

## 易错点
1. **没先化标准形式就套公式**，P(x) 取错。
2. 通解公式里的积分常数处理不当：
   y = e^(−∫P dx) · [∫Q·e^(∫P dx) dx + C]
   中间那个 ∫P dx **不需要加常数**（加了会和外面的 C 合并），很多人在这里多写一个 C。
3. 伯努利方程换元后忘了把 dy/dx 也跟着换。
4. 应用题列方程时把"变化率"的方向搞反（增长还是衰减）。
5. 忘写"通解"的 C，或初值条件代入时机错。

## 解题思路
识别类型 → 化标准形 → 选对应方法：
一阶线性直接套公式；伯努利先换元；齐次先换 u=y/x；变量可分离直接分离。
应用题先设未知函数、写出变化率的物理含义，再列方程。

## 验收标准
能默写一阶线性通解公式并独立解 5 道不同类型的一阶方程，其中至少 1 道应用题。
